# Study Latin - Веб-приложение для изучения латинского языка

## Описание проекта

Study Latin - это образовательное веб-приложение для изучения латинских терминов и крылатых выражений. Проект разработан в рамках учебного задания для Цифровой Кафедры МФТИ по курсу "Python для решения прикладных задач".

## Основные функции

- Словарь латинских терминов с транскрипциями и переводами
- Коллекция крылатых латинских выражений
- Возможность добавления новых терминов и выражений


## Установка и запуск

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите проект: `python3 manage.py runserver --insecure`
